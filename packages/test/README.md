# @switchyard-ts/test

Testing Switchyard machines: `shortestPaths` / `simplePaths` for model-based tests, `coverage()`
of states and transitions, `toBeIn` (vitest/jest) and `assert.machineIn` (QUnit), and
`useManualClock` for `@after`.

Guide: **https://joegaudet.com/switchyard/guide/#/testing** · MIT
