# @switchyard-ts/graph

Draw Switchyard machines: `toGraph()`, then Mermaid (`toMermaid`), Graphviz (`toDot`) or SVG laid
out by ELK (`toSvg`); the interface view (`describeInterface`) and the live actor tree
(`topology`). `@switchyard-ts/graph/viewer` is `<switchyard-diagram>`, a live, highlighting chart.

Guide: **https://joegaudet.com/switchyard/guide/#/diagrams** · MIT
