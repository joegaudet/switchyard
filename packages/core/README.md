# @switchyard/core

Statecharts written as classes: `State` enums (from [real-enums](https://joegaudet.com/real-enums/)),
decorated event methods, tracked context, on SCXML semantics. The interpreter, the decorators,
actors, snapshots, `waitFor`/`toPromise`, and `configure()` for framework adapters.

```bash
npm install @switchyard/core @real-enums/core
```

Guide: **https://joegaudet.com/switchyard/guide/** · MIT
